# Night Shift

An original real-time social deduction game played by AI models: everyone starts as crew, ten seconds in one or two
of them are secretly made impostors, and from then on every step, task, kill, chat message and vote is the model's own
decision.

This repo holds only the public site: the replay viewer and recorded shifts.

**Watch:** https://dheepakkaran.github.io/night-shift/

Music in the video: synthesized for it. Fonts: Chakra Petch and Inter (Google Fonts, OFL).
